## Brand & Style

This design system establishes an intellectual, highly disciplined, and modern workspace tailored for high-achieving university students, researchers, and academic professionals. It fuses the tactile, fluid organization of modern knowledge bases with the precise, keyboard-centric craftsmanship of high-performance engineering tools.

The interface prioritizes cognitive clarity and deep focus. The emotional tone is authoritative yet frictionless—reducing cognitive load through structured density, crisp spatial alignment, and deliberate typographic contrast.

The visual style is **Academic Minimalist**:
- **Structured Workspace Rhythm:** High information density achieved without visual chaos, utilizing rhythmic vertical cadences, clear horizontal rules, and hairline compartmentalization.
- **Subtle Modern Surfaces:** Cool off-white canvas foundations counterbalanced by pure white structural tiles, fine micro-borders, and whisper-soft diffused drop shadows.
- **Focused Energetic Accents:** An electric violet focal accent anchors critical action states, progress indicators, and AI synthesis surfaces without overwhelming academic prose.

## Colors

The color palette centers on a disciplined academic scale. Contrast is engineered for effortless legibility under varying library and late-night study lighting conditions, balancing clean surfaces with punchy syntactic accents.

### Palette Architecture
- **Primary (`#7C3AED`):** Soft Electric Violet. Serves as the interactive anchor, synthetic insight indicator, active state highlight, and focused focus-ring accent.
- **Secondary (`#1E1B4B`):** Deep Academic Indigo. Utilized for strong contextual headers, key navigation anchors, dark-pattern toggles, and high-impact semantic blocks.
- **Tertiary (`#10B981`):** Scholastic Emerald. Deployed for completion markers, mastery statuses, grade improvements, and verified source citations.
- **Neutral (`#0F172A`):** Deep Slate. Defines core typography, crisp vector iconography, and structural micro-delimiters.

### Functional & Surface Tones
- **Canvas Base:** `#F8FAFC` (Slate-50 cool off-white) creates a glare-free, paper-like foundation.
- **Elevated Tiles & Modals:** `#FFFFFF` (Pure White) surfaces frame focus areas and structured data lists.
- **Structural Borders:** Hairline `#E2E8F0` (Slate-200) outlines cards and input zones, while `#F1F5F9` (Slate-100) separates inline list rows.
- **Feedback & Deadlines:** Urgent deadlines invoke `#EF4444` (Rose-500); active preparation and revisions invoke `#F59E0B` (Amber-500).

## Typography

The typographic hierarchy pairs **Plus Jakarta Sans** for structural headers with **Manrope** for analytical prose and data representations.

- **Plus Jakarta Sans (Headings):** Selected for its balanced geometry and approachable precision. Headlines employ negative tracking (`-0.02em` to `-0.03em`) to maintain tightness, authority, and editorial clarity.
- **Manrope (Body & UI Elements):** Features open counters and distinct glyph variations that retain clarity during long reading sessions, multi-level outlines, and rapid scanning of technical summaries.
- **Micro Badges & Metadata:** `label-sm` utilizes uppercase rendering paired with wider letter-spacing (`0.05em`) to balance dense data tags, status indicators, and keyboard shortcuts without crowding surrounding content.

## Layout & Spacing

The layout model implements a fluid responsive framework based on an 8px modular baseline (with 4px micro-adjustments).

### Grid Configuration
- **Desktop (1024px+):** 12-column dynamic fluid grid. Standard canvas margin is `2rem` (`space-xl`), gutters set to `1.5rem` (`space-lg`). Sidebars lock to `280px` fixed widths, letting academic content panes dynamically scale up to a maximum reading container width of `1200px`.
- **Tablet (768px – 1023px):** 8-column layout. Gutters and canvas margins scale to `1.5rem` (`space-lg`). Peripheral panes collapse into sliding off-canvas drawers.
- **Mobile (320px – 767px):** 4-column single-stream stack with `1rem` margins and `1rem` gutters. Maximizes vertical thumb sweep and full-bleed list readability.

### Ergonomics & Mobile Adaptations
Mobile viewports prioritize ergonomic single-hand reachability. Primary actions relocate to a sticky, elevated bottom control rail (height: `64px`). Informational headers remain docked to the top viewport edge using translucent light blurs to retain contextual positioning during fluid scrolls.

## Elevation & Depth

Visual depth is achieved through layered structural surfaces and ultra-soft, atmospheric multi-tier shadows rather than heavy drop-shadows.

### The Elevation Stack
- **Level 0 (Canvas):** Base background `#F8FAFC`. Completely non-elevated; houses non-clickable organizational headers, calendar rails, and background watermarks.
- **Level 1 (Card / Tile Surfaces):** Pure White `#FFFFFF` with a crisp `1px solid #E2E8F0` hairline border and ambient multi-tier shadow: `0 1px 3px rgba(15, 23, 42, 0.04), 0 4px 6px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Hover States & Inline Popovers):** Elevated `#FFFFFF` surfaces with subtle border contrast (`#CBD5E1`) and an expanded soft diffusion shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.04), 0 4px 6px -2px rgba(15, 23, 42, 0.02)`.
- **Level 3 (Modals, Command Bars & Drawers):** `#FFFFFF` paired with an ambient tinted drop shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.03)`. Backed by an ultra-clean scrim (`rgba(15, 23, 42, 0.3)` with `backdrop-filter: blur(4px)`).

## Shapes

The design system adopts **Roundedness 2**, utilizing a foundational radius of `0.5rem` (`8px`) for standard interactive components, stepping up to `1rem` (`16px`) for cards and dialogs, and `1.5rem` (`24px`) for prominent contextual containers.

- **Base Radius (`0.5rem` / `8px`):** Input fields, inline code snippets, dropdown menus, button controls, and tooltips.
- **Large Radius (`1rem` / `16px`):** Course cards, AI chat bubbles, document summary previews, and slide-in panels.
- **Extra Large Radius (`1.5rem` / `24px`):** Floating navigation bars, prominent modal sheets, and highlight metric widgets.
- **Pill Radius (`9999px`):** Status badges, tag filters, user avatars, and progress meters.

## Components

### Buttons
- **Primary:** Background `#7C3AED`, label `#FFFFFF`, border `transparent`. Hover transitions to `#6D28D9` with active transform `scale(0.98)`. Border radius `0.5rem`, padding `0.625rem 1.25rem`.
- **Secondary:** Background `#FFFFFF`, label `#0F172A`, border `1px solid #E2E8F0`. Hover triggers background `#F8FAFC` and border `#CBD5E1`.
- **Ghost / Minimalist:** Background `transparent`, label `#64748B`. Hover state applies `#F1F5F9` background with `#0F172A` text color.

### Chips & Badges
- **Status Pills:** Height `24px`, padding `0 0.625rem`, border radius `9999px`. Rendered with `label-sm` uppercase styling.
  - *Completed:* `#ECFDF5` background, `#047857` text, subtle `#A7F3D0` border.
  - *In Progress:* `#FFFBEB` background, `#B45309` text, subtle `#FDE68A` border.
  - *Urgent:* `#FEF2F2` background, `#B91C1C` text, subtle `#FECACA` border.

### Input Fields
- **Default:** Background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius `0.5rem`, height `42px`, typography `body-md`.
- **Focus:** Border transitions to `#7C3AED` accompanied by an electric halo outline: `box-shadow: 0 0 0 3px rgba(124, 58, 237, 0.12)`.
- **Placeholder:** `#94A3B8` font color.

### Checkboxes & Selection Controls
- **Checkboxes:** Size `18px x 18px`, radius `4px`, border `1.5px solid #CBD5E1`. Checked state fills `#7C3AED` with an internal white vector checkmark.
- **Radios:** Size `18px x 18px`, outer ring `#CBD5E1`, active fill hosts a concentric `#7C3AED` center dot (diameter `8px`).

### Cards & Structured Lists
- **Cards:** Pure `#FFFFFF` surfaces with a continuous `1px solid #E2E8F0` hairline border and Level 1 elevation. Internal padding defaults to `1.25rem` (`20px`).
- **Interactive List Rows:** Separated by hairline borders (`#F1F5F9`). Hover initiates a crisp `#F8FAFC` background shift with smooth `150ms ease-out` timing.

### Academic Domain Components
- **Progress Trackers:** Track height `6px`, background `#E2E8F0`, pill corner radius. Fill features a smooth gradient from `#7C3AED` to `#9333EA`.
- **AI Prompt Bar:** Elevated command search pill (`52px` height) with `#FFFFFF` fill, `1px solid #CBD5E1` border, Level 2 elevation, embedded violet trigger shortcut (`⌘K`), and instant focus halo.
